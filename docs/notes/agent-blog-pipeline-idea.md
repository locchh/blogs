# Idea: agents that help me collect, log, and draft

Noted 2026-10-28. Not about any one post. This is how I want to run idea capture and drafting for the blog.

## The idea

- **Collect.** Agents gather raw material for me: ideas, passing thoughts, related documents and links.
- **Log.** Agents keep a running log of that material. The log is the raw notes behind a future post.
- **Draft.** From the log, agents draft posts, including "top trend" roundups like the monthly interesting-things posts.
- **Review.** Multiple agents with roles, at least a **writer** and a **reviewer**. The reviewer checks facts, sources, and the plain-language rules in `CLAUDE.md`.

## Open questions

- Where does the log live: this folder, a separate store, or the agent's memory?
- How does the reviewer enforce the style rules, and when does it stop?
- What triggers a draft: a schedule, a number of collected items, or me asking?
